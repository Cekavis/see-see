# Feature Specification: WebDAV 配置同步

**Feature Branch**: `018-webdav-config-sync`

**Created**: 2026-09-18

**Status**: Draft

**Input**: User description: "通过 WebDAV 上传/下载配置（模型+提示词，不含快捷键），放在常规页，提供默认为 see-see 的可自定义远程根目录，记住 WebDAV 配置并支持跨平台同步。"

## User Scenarios & Testing

### User Story 1 - 保存 WebDAV 连接设置 (Priority: P1)

用户在“常规”页填写 WebDAV 地址、用户名、密码和远程根目录，并保存后即可在以后继续使用，无需每次重新填写。远程根目录默认为 `see-see`，用户可以改成自己的目录。

**Why this priority**: 没有可复用的连接设置，上传和下载无法形成可用的同步流程。

**Independent Test**: 在常规页保存连接信息，关闭并重新打开设置页，确认地址、用户名和远程根目录仍显示，密码显示为已保存状态但不回显明文。

**Acceptance Scenarios**:

1. **Given** WebDAV 设置为空，**When** 用户打开常规页，**Then** 远程根目录显示 `see-see`，其余连接字段为空。
2. **Given** 用户填写有效地址、用户名、密码和自定义远程根目录并保存，**When** 用户重新进入常规页，**Then** 地址、用户名、远程根目录和“已保存密码”状态仍然存在。
3. **Given** 远程地址使用不安全协议或远程根目录包含无效路径片段，**When** 用户保存，**Then** 保存失败并显示可理解的错误，已有设置保持不变。

### User Story 2 - 上传模型与提示词配置 (Priority: P1)

用户可以在常规页将当前模型配置和提示词配置上传到 WebDAV 远程根目录，供其他设备下载。上传内容不包含提示词快捷键，也不包含 API Key 等本机凭据。

**Why this priority**: 上传是跨设备共享配置的主要入口。

**Independent Test**: 使用可写 WebDAV 服务，上传包含多个模型和提示词的本地配置，确认远程根目录生成同步文件，文件中有模型和提示词但没有快捷键、API Key 或 WebDAV 密码。

**Acceptance Scenarios**:

1. **Given** WebDAV 设置已保存且本地有模型和提示词，**When** 用户点击上传配置，**Then** 远程根目录被创建（如需要），配置文件成功写入，并显示上传的模型和提示词数量。
2. **Given** 本地包含提示词快捷键和模型 API Key，**When** 用户上传，**Then** 远程文件不包含这些字段或值，本地快捷键和 API Key 不受影响。
3. **Given** WebDAV 认证、网络或写入失败，**When** 用户上传，**Then** 显示失败原因和可重试状态，本地配置不被修改。

### User Story 3 - 下载并合并配置 (Priority: P1)

用户可以从 WebDAV 下载配置，在不破坏本机快捷键的前提下更新或新增模型和提示词。已有配置优先按稳定 ID 匹配，其次按名称匹配；本地仅有的配置保留。

**Why this priority**: 下载让另一台设备能够恢复共享配置，同时避免覆盖本机独有设置。

**Independent Test**: 在一台设备上传配置，在另一台设备配置相同 WebDAV 后下载，确认模型和提示词出现，原有快捷键保持不变，本机独有配置仍存在。

**Acceptance Scenarios**:

1. **Given** 远程文件有效且本地存在同 ID 或同名配置，**When** 用户点击下载配置，**Then** 远程模型和提示词内容更新到本地，原有提示词快捷键保持不变。
2. **Given** 远程文件包含本地不存在的配置，**When** 用户点击下载配置，**Then** 新配置被添加，新增提示词没有快捷键。
3. **Given** 远程文件不存在、格式无效或内容不符合约束，**When** 用户点击下载配置，**Then** 下载失败且本地配置保持不变。

## Edge Cases

- WebDAV 根目录为空时使用 `see-see`；路径必须是相对目录，不能包含 `.`、`..`、反斜杠、查询字符串或片段。
- WebDAV 服务已存在远程根目录时，上传应继续工作；服务不允许创建目录时，应给出明确错误。
- 远程文件只包含部分配置时，下载只新增或更新文件中的项目，不删除本地其他项目。
- 远程内容超出合理大小、包含重复名称、未知协议或超长字段时，下载应拒绝整个文件并保持本地事务不变。
- 保存新密码为空时保留原密码；明确清除密码后，上传和下载应要求重新填写密码。
- 上传或下载进行中按钮应禁用，重复点击不得并发执行多个同步操作。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 在“常规”页提供 WebDAV 地址、用户名、密码和远程根目录字段。
- **FR-002**: 系统 MUST 将远程根目录默认设置为 `see-see`，并允许用户修改。
- **FR-003**: 系统 MUST 持久化 WebDAV 地址、用户名和远程根目录，并将密码保存在本机凭据存储中；密码不得回显。
- **FR-004**: 系统 MUST 提供保存设置、上传配置和下载配置操作，并定义加载、进行中、成功、失败和重试状态。
- **FR-005**: 上传文件 MUST 包含模型配置元数据、提示词名称与正文，以及支持恢复当前模型选择所需的非敏感信息。
- **FR-006**: 上传文件 MUST NOT 包含提示词快捷键、模型 API Key、WebDAV 密码或其他本机凭据。
- **FR-007**: 下载 MUST 按稳定 ID 优先、名称其次匹配模型和提示词；更新提示词时 MUST 保留本机快捷键；新增提示词 MUST 不设置快捷键。
- **FR-008**: 下载 MUST 以一次性校验和事务方式应用，远程文件无效时不得部分修改本地配置。
- **FR-009**: 系统 MUST 支持 HTTPS WebDAV；仅对本机回环地址允许 HTTP，并在其他不安全地址下拒绝保存或同步。
- **FR-010**: 系统 MUST 将配置文件放在配置的远程根目录下，并使用固定、应用专属的文件名，避免与其他应用冲突。
- **FR-011**: 系统 MUST 对远程认证、网络、HTTP 状态码、文件不存在和目录创建失败提供用户可理解的错误。
- **FR-012**: 下载和上传操作 MUST 在跨平台环境中使用相同的配置文件格式和匹配规则。

### User Experience and UI Requirements

- **UX-001**: WebDAV 同步区域应复用常规页已有的分组、Field、Button、通知和禁用状态样式。
- **UX-002**: 密码字段应支持留空保留已保存密码，并提供明确的清除动作；界面不得显示密码明文。
- **UX-003**: 上传和下载完成后应显示数量和操作结果；失败时应保留表单内容并提供重试。
- **UI-001**: 控件必须有可访问名称、键盘可操作，并在窄窗口中保持可用布局。
- **UI-002**: 代表性视觉检查至少覆盖桌面宽度和窄窗口宽度，检查字段间距、按钮状态和错误提示层次。

### Key Entities

- **WebDAV 连接设置**: 地址、用户名、远程根目录和本机保存的密码状态；只在本机保存，不上传。
- **配置同步快照**: 版本化的模型元数据、提示词内容和当前模型选择；不包含快捷键或凭据。
- **同步结果**: 上传或下载的模型与提示词数量及成功或失败状态。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 用户在首次填写连接信息后，后续打开常规页无需再次输入密码即可完成上传或下载。
- **SC-002**: 在正常 WebDAV 网络条件下，包含 50 个模型和 200 个提示词的配置上传或下载在 10 秒内完成。
- **SC-003**: 在跨平台验收中，远程快照中的模型和提示词内容 100% 可在另一平台恢复，快捷键和凭据字段 100% 不被远程文件覆盖。
- **SC-004**: 无效远程文件或网络失败时，本地模型和提示词数据保持失败前状态，用户可通过一次重试继续操作。

## Assumptions

- WebDAV 服务支持基本认证、HTTPS 和标准的目录创建、上传与下载请求。
- 同步文件使用应用专属名称，远程根目录由用户负责选择访问权限；应用不管理 WebDAV 服务端账号。
- 模型 API Key 仍按每台设备的现有本机凭据策略保存，需要在新设备分别配置。
- 本次同步范围只包括模型配置和提示词配置，不包括历史记录、桌面偏好、截图快捷键或 WebDAV 连接密码。

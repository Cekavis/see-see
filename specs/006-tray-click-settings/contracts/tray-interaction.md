# Tray Interaction Contract

| Input | Result |
|-------|--------|
| Left button released | Restore, show, and focus the existing settings window; do not show the tray menu |
| Left button pressed | No window action |
| Right button interaction | Preserve native tray-menu display behavior |
| Middle button, movement, enter, leave, or double-click | No new window action |
| Existing tray menu command | Preserve the current capture, open, or quit action |

# Quickstart
1. Run `powershell.exe -Command "npm test -- --run src/views/Prompts.test.tsx src/views/Settings.desktop.test.tsx"`.
2. Run `cargo test --manifest-path src-tauri/Cargo.toml`.
3. Run `powershell.exe -Command "npm run build"`.
4. Review prompt list at representative desktop width and verify two aligned action rows.
